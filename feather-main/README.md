# i cerf  (com.icerf.iq)

Fork of [Feather](https://github.com/claration/feather) (GPL-3.0). Uses Zsign for on-device signing.
Changes: new name/bundle id/icon, App Store style "Today" tab, signed apps get the `.icerf` suffix on their bundle id automatically.
This project stays under GPL-3.0; original copyright notices and credits are kept.
Build: push to GitHub, Actions -> "Build i cerf IPA" -> Run workflow (submodules are fetched automatically).
